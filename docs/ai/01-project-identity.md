# Project Identity

## Product

- Repository: `kiletw/SpineViewerWPF`
- Product name: `SpineViewerWPF`
- Legacy line: v2
- Modernization line: v3
- Planned CLI executable: `spineviewerwpf`
- Planned MCP server name: `spineviewerwpf-mcp`

## Product Purpose

Open historical and current Spine assets quickly, select animations and skins, preview them reliably, and capture or export output.

## Primary v3 Experience

The default experience is **quick browse**:

```text
Open or drop asset
→ discover atlas/textures
→ detect Runtime
→ fit viewport
→ choose previous or first animation
→ play immediately
```

## Differentiators to Preserve

- multiple historical Spine Runtime lines
- practical viewer workflow
- PNG/GIF or sequence export behavior where verified
- transparent/background preview options
- version-aware diagnostics

## Non-Goals for Initial v3

- general-purpose Spine editor
- Runtime source editor
- scene compositor
- plugin marketplace
- remote service
- cloning another SpineViewer project
